# Aica Dumbest Thing

One line, 200 characters at most, on the dumbest thing my agent did
today: it spent an hour proving to a transcript gate that it wrote one
line — then the gate asked for the session where it proved it.

## How it works

- `main.py` (standard library only, deterministic) writes the line to
  `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

Run `python3 main.py` to produce the output file.
